Statistics

Average and Spread

Important measures

Mean = sum of values / number of values
Median = middle value when arranged in order
Mode = most common value
Range = largest value - smallest value

Worked example

Find the mean of 4, 6, 7, 9, 9.

Solution: total = 35; number = 5; mean = 35 / 5 = 7.

Answer: 7
