Algebra

Core Skills

Definitions

Algebra uses letters and symbols to represent numbers and quantities. This allows us to write rules and solve equations.

(a + b)² = a² + 2ab + b²
(a - b)² = a² - 2ab + b²
a² - b² = (a - b)(a + b)

Worked example 1

Solve: 3x + 7 = 22

Solution:

Subtract 7 from both sides: 3x = 15

Divide both sides by 3: x = 5

Answer: x = 5

Worked example 2

Factorise: x² - 9

Solution:

Recognise the difference of squares: a² - b² = (a - b)(a + b)

x² - 9 = x² - 3² = (x - 3)(x + 3)

Answer: (x - 3)(x + 3)
