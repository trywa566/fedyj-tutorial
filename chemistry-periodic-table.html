Periodic Table

Atomic Structure & Trends

Definition

The periodic table is a tabular arrangement of elements in order of increasing atomic number.

Elements in the same group have similar chemical properties because they have the same number of electrons in their outer shell.

Electronic configuration method

Electrons are arranged in shells around the nucleus. For example:

  • Hydrogen: 1
  • Helium: 2
  • Lithium: 2,1
  • Sodium: 2,8,1
  • Chlorine: 2,8,7

In higher chemistry, we write configurations using subshell notation such as 1s² 2s² 2p⁶ 3s¹.
