Install FEDY.J's Tutorial

Offline App

Make the site available offline

FEDY.J's Tutorial is a Progressive Web App. To install on mobile or desktop:

  1. Open the site in your browser (Chrome/Edge/Firefox).
  2. Look for "Install" or "Add to Home screen" option in the browser menu.
  3. Tap to install — the site will run like an app and work offline after first load.

If you want a ZIP for local hosting, download the repository and run a static server (see README).

Search

Use the search box in the header to find topics quickly. Search works offline after the index is cached.
